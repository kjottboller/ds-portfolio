# Анализ резюме HeadHunter — EDA

Первый учебный проект курса Skillfactory (2024): подготовка и разведывательный анализ базы резюме hh.ru (≈ 44,7 тыс. строк, 12 признаков).

## Что сделано
- Исследование структуры данных.
- Преобразование «сырых» текстовых полей в признаки: образование, пол и возраст, опыт работы в месяцах, город, готовность к переезду и командировкам, занятость и график, желаемая зарплата в рублях (пересчёт по курсам валют).
- Исследование зависимостей: распределения возраста, опыта и желаемой зарплаты; зарплата по городам, образованию, готовности к переезду.
- Очистка: дубликаты, пропуски, выбросы.

## Данные
`hh_database.csv` (≈ 450 МБ) в репозиторий не включён.

## Стек
pandas, NumPy, plotly, seaborn, matplotlib.

> Ноутбук содержит интерактивные графики plotly и весит ~8 МБ, поэтому GitHub может не отрисовать его в превью — лучше открыть через [nbviewer](https://nbviewer.org/).
