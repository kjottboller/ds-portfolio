# Анализ вакансий HeadHunter — SQL

Учебный проект Skillfactory: анализ базы вакансий hh.ru (PostgreSQL) SQL-запросами из Python.

## Что сделано
- Подключение к PostgreSQL через SQLAlchemy / psycopg2, параметры доступа — в `.env` (не хранится в репозитории, шаблон — `.env.example`).
- Предварительный анализ таблиц: вакансии, работодатели, регионы, сферы деятельности.
- Детальный анализ: зарплатные вилки, графики и типы занятости, требуемый опыт.
- Анализ работодателей: лидеры по числу вакансий, география, работодатели без указанной сферы.
- Предметный анализ вакансий для Data Scientist (фильтрация по названию и ключевым навыкам).
- Парсинг списка городов-миллионников из Википедии (BeautifulSoup) и соединение с данными базы.

В запросах используются JOIN (в т. ч. LEFT JOIN), агрегаты, GROUP BY / HAVING, подзапросы, фильтрация по шаблонам.

## Запуск
Скопировать `.env.example` в `.env` и заполнить параметры подключения. База — учебная (Skillfactory), без доступа к ней ноутбук можно читать с сохранёнными выводами.

## Стек
PostgreSQL, SQLAlchemy, psycopg2, pandas, requests, BeautifulSoup.
