# Кредитный скоринг — ШИФТ ML 2025

Отборочное задание ШИФТ (2025): предсказать вероятность дефолта по займу (`итоговый_статус_займа`). Train — около 1,2 млн строк, более 100 признаков.

## Что сделано
- EDA: дубликаты, пропуски, выбросы, неинформативные признаки, распределения и корреляции.
- Кодирование категориальных признаков (рейтинг, владение жильём, подтверждение дохода и др.), нормализация.
- Baseline: логистическая регрессия на 7 признаках, ROC-AUC = 0.648 (на обучающей выборке).

## Что планируется
- Отложенная выборка / кросс-валидация вместо оценки на train.
- Единый пайплайн предобработки для train и test (sklearn `Pipeline`).
- Использование всех подготовленных признаков, градиентный бустинг (CatBoost / LightGBM).

## Данные
Файлы соревнования `shift_ml_2025_train.csv` / `shift_ml_2025_test.csv` в репозиторий не включены.

## Стек
pandas, NumPy, scikit-learn, seaborn, matplotlib.
