# Зарплаты в Data Science — исследование и проверка гипотез

Учебный проект Skillfactory. HR-агентство хочет понять тренды зарплат в Data Science за 2020–2022 гг.
Датасет: [Data Science Job Salaries (Kaggle)](https://www.kaggle.com/datasets/ruchi798/data-science-job-salaries), лежит в `data/ds_salaries.csv`.

## Вопросы и использованные тесты
| Вопрос | Тест |
|--------|------|
| Растут ли зарплаты Data Scientist год от года? | ANOVA |
| Зарплаты Data Scientist vs Data Engineer в 2022 г. | U-критерий Манна — Уитни |
| Зарплаты Data Scientist в компаниях разного размера | Критерий Краскела — Уоллиса |
| Связаны ли наличие должностей DS/DE и размер компании? | Хи-квадрат |

Плюс две собственные бизнес-гипотезы. Перед каждым тестом — визуализация и проверка распределения на нормальность.

## Основные выводы
- На зарплату Data Scientist влияют опыт, размер компании и страна.
- Зарплаты по годам статистически значимо различаются.
- В 2022 г. Data Scientist получают больше, чем Data Engineer.
- Компании среднего размера платят больше, чем крупные.

## Стек
pandas, SciPy, statsmodels, seaborn, matplotlib.
